# Finora

Finora is a simple desktop finance tracking application built with Python.

It helps you keep track of your income and expenses in a clear and simple interface.

## Download
Windows

The easiest way to use Finora is to download the latest Windows release.

Go to the Releases section on GitHub and download:

Finora.exe

No Python installation is required.

##Features
Add income and expenses manually
Categorize expenses
Edit and delete transactions
Monthly overview
Switch between different months
Income vs. expenses chart
Expenses by category chart
Personal greeting
Persistent local data storage
Desktop application interface
Screenshots

Screenshots will be added in a future version.

##Technologies
Python
Tkinter
SQLite
Matplotlib
PyInstaller
Development

If you want to run Finora from source instead of using the Windows release:

Requirements
Python 3.14 or newer
Installation

Clone the repository and install the required packages:

pip install -r requirements.txt

Then start the application:

python main.py
Data

Finora stores financial data locally using SQLite.

The local database is not included in the GitHub repository and is excluded using .gitignore.

##Version

Current version: 1.0.0
